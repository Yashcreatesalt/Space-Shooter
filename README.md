# 🚀 Space Shooter

A simple 2D arcade shooter made using Python and Pygame.

## 🎮 Controls
- Left Arrow → Move Left
- Right Arrow → Move Right
- Space → Shoot

## 📦 Installation
```bash
pip install -r requirements.txt
```

## ▶️ Run Game
```bash
python main.py
```

## 🧠 Features
- Player shooting mechanics
- Enemy spawning
- Collision detection
- Score system
- Game over condition
